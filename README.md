# Flask Voting Application with Git Versioning

## Project Description

This project is a simple web application that demonstrates how different URLs can perform different tasks.

Version 1 provides basic application and health-check pages. Version 2 adds a simple voting system where users can vote for candidates, view the current results, and reset all votes.

The application stores voting information temporarily while the application is running.
